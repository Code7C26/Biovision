Comandos GitHub

\-Ejecutar el git bash como admin

\-Para entrar a la carpeta donde se tendrá todo lo que se subirá a GitHub

\-Comando **cd** para ir a la carpeta

**-mkdir** para crear carpetas

**-git clone** con esto copias la URL y la pegas

\-Hay que entrar en la carpeta donde esta todo lo que se subirá a **GitHub** y donde esta copiado **el** **repo**

\-Se copia el **repo** y se hace **CD** a la **carpeta**

\-Hago un **cambio** y se hace **git** **add** . 

**-git** **status** para ver si esta el cambio

**-git** **commit** **-m ""<-- MENSAJE""**

\-(**git commit -am <-- ADD Y MENSAJE)**

\-No hace falta hacer **git** **add** . solamente la primera vez luego simplemente con el **git** **commit** **-am** esta

\-Luego **git** **push** **origin** **main** <-- solo la primera vez luego solo **git** **push**

\-Para ver los cambios realizados por otros contribuyentes **git** **pull**
